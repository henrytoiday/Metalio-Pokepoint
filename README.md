# Gói font và từ điển — Metalio-Pokepoint

Đây là các gói tuỳ chọn cho firmware. Giải nén từng gói vào **thư mục gốc** thẻ nhớ. Mỗi gói đã có sẵn thư mục `fonts/` hoặc `dictionaries/`, nên file tự vào đúng chỗ.

- `fonts-Literata-*.zip`, `fonts-BeVietnamPro-*.zip`: font có ký tự IPA, chia gói theo cỡ chữ. Giấy phép SIL OFL (Literata, Be Vietnam Pro, Noto).
- `tu-dien-anh-viet.zip`: từ điển Anh–Việt, nguồn OVDP.
- `tu-dien-anh-anh.zip`: từ điển Anh–Anh, nguồn Wiktionary (CC BY-SA).

Hướng dẫn chi tiết xem ở [README chính](https://github.com/huymelon/Metalio-Pokepoint#readme).
